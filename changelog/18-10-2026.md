# 18-10-2026

[← Back to changelog index](../CHANGELOG.md)

## Unreleased

- [Added] Qwen Code integration through `anchor init-qwencode`, including project MCP registration, `QWEN.md`, session context, opt-in prompt reminders, and chart refresh through `Stop` and `SessionEnd`.
- [Added] DeepSeek Harness integration through `anchor init-deepseek`, generating hook configuration and a Cordis patch overlay for the official `dsh-hooks-codex` bridge and MCP client. Launch with `--patch .memoryanchor/deepseek/cordis.patch.yml` in a profile with compatible bridge and MCP packages; initialization does not activate the overlay automatically.
- [Added] ZCode integration through `anchor init-zcode`, registering user-level `hooks.events` in `~/.zcode/cli/config.json` and project MCP in `.zcode/config.json`. Existing disabled settings are preserved; global prompt dispatchers respect each workspace's reminder selection.
- [Changed] Each new platform owns its initialization module, CLI registration, hook schemas, and input/output adapters. Platform interfaces remain independent so they can evolve separately; shared context rendering, reminders, diagnostics, and refresh logic stay in `public`.
- [Added] Combined initialization and `anchor prompt-hook` support all three platforms. Hook wrappers resolve the invocation workspace, skip projects without `.memoryanchor`, and release parser workers after refresh. DeepSeek Harness and ZCode use `Stop` for refresh because their integrations have no `SessionEnd` event.
- [Fixed] `anchor prompt-hook --off` without agent names clears every workspace reminder selection.
- [Fixed] MCP initialization tests now expect `get_project_state` alongside `get_chart` and `get_file`, resolving failures caused by stale two-tool assertions. Initialization subprocess tests explicitly isolate `HOME` and `HERMES_HOME`.
- [Updated] README and project specification document platform setup, configuration locations, supported lifecycle events, and DeepSeek startup requirements.
- [Tested] The complete local `npm test` pipeline passes build and type checks plus 277 tests across 42 suites, including separate hook tests for each new platform. Full sessions in the Qwen Code, DeepSeek Harness, and ZCode applications have not been exercised locally.
