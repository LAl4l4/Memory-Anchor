## 1.10.1

- [Added] File exclusions through root and nested `.gitignore` files and an optional workspace-root `.memoryanchorignore`, using Git ignore syntax. Anchor exclusions supplement Git rules; built-in exclusions remain mandatory.
- [Changed] Full builds and incremental subtree renders share workspace-relative exclusion semantics. Ignored files are skipped during traversal and omitted from parsed dependency targets.
- [Fixed] Ignore-rule additions, edits, and deletions trigger a full rebuild on the next lifecycle refresh, removing obsolete chart entries and restoring newly included files. Rule snapshots and existing directory metadata also detect changes hidden from Git status.
- [Updated] README and project specification document rule syntax, precedence, and automatic refresh behavior. Global Git excludes and `.git/info/exclude` are intentionally not loaded.
- [Tested] Build and source/test type checks pass. The full suite passes 282 of 283 tests, including all six new exclusion regressions; the real OpenCode integration test exceeds its 60-second timeout in this environment.
