## Entries

- `init-claude` now writes `@AGENTS.md` into `CLAUDE.md` instead of the sentence `- Follow \`AGENTS.md\` for Memory Anchor rules.`. Claude Code loads `CLAUDE.md` but not `AGENTS.md`, and a plain sentence does not import anything, so the Memory Anchor rules never reached the session context. Re-running init upgrades the legacy sentence in place and keeps the rest of the file. A `CLAUDE.md` that is a symlink to `AGENTS.md` is left unchanged, because it already loads the rules and a self-import would duplicate them. Copilot, CodeBuddy and Qwen keep the existing pointer line.
